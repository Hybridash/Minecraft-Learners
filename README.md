A beginner's guide to playing modded Minecraft with [Prism Launcher](https://prismlauncher.org), a free and open-source launcher that keeps each modpack or mod setup in its own separate "instance".

## The super-short version

1. **Buy** Minecraft: Java Edition at [minecraft.net](https://www.minecraft.net).
2. **Install** Prism from [prismlauncher.org/download](https://prismlauncher.org/download).
3. **Sign in:** click **Settings** (top) → **Accounts** (left) → **Add Microsoft** (right).
4. **New instance:** click **Add Instance** (top-left) → type a name → click a version → pick **Fabric** → **OK**.
5. **Add mods:** click your instance → **Edit...** (right) → **Mods** (left) → **Download Mods** (right) → search → **Select mod for download** → **Review and confirm** → **OK**.
6. **Play:** click your instance → **Launch** (right).

Stuck on a step? The numbered guides above explain every click.

## Words you'll see

| Word | Meaning |
|---|---|
| **Instance** | A separate copy of Minecraft with its own version, mods, worlds and settings. Mods in one instance don't affect the others. |
| **Mod loader** | The program that lets mods run: **Fabric**, **NeoForge**, **Forge** or **Quilt**. A mod only works with the loader it was made for. |
| **Modpack** | A ready-made set of mods and settings that someone else put together. |
| **Modrinth / CurseForge** | The two main websites for mods and modpacks. Prism can download from both. |
| **Java** | The software Minecraft Java Edition runs on. Prism downloads the right version for you. |
