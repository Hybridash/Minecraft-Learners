# 3. Make your first instance

An **instance** is a separate copy of Minecraft. You can have as many as you like: one plain vanilla one, one for a modpack, one for testing mods, and so on.

## Create it

1. Click **Add Instance** (top left).
2. Make sure **Custom** is selected on the left.
3. Type a **Name**, for example `My Mods 1.21`.
4. Pick a **Minecraft version** from the list. Tip: for mods, pick a version that the mods you want support. Popular mods are usually updated for the newest versions first.
5. Under **Mod loader** at the bottom, pick one:

| Loader | Good for |
|---|---|
| **None** | Plain Minecraft, no mods. |
| **Fabric** | Performance mods (Sodium, Lithium), small quality-of-life mods. Fast to update. Most mods also need **Fabric API**. |
| **NeoForge** | Big content mods (new machines, magic, dimensions) on newer versions. |
| **Forge** | The same kind of mods on older versions (1.20.1 and earlier). |
| **Quilt** | Mostly runs Fabric mods too. Pick it only if a mod asks for it. |

6. Click **OK**. The instance appears in the main window.

## Play it

Select the instance and click **Launch** (right side). The first launch takes a while because Prism downloads the game.

## Useful buttons on the right

- **Edit**: mods, worlds, settings, resource packs and more for this instance.
- **Folder**: opens the instance's files on your computer.
- **Copy**: duplicates the instance, which is handy before trying risky mods.
- **Delete**: removes the instance and everything in it, including worlds.
