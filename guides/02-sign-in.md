# 2. Sign in with your Microsoft account

You need a Microsoft account that **owns Minecraft: Java Edition** (buy it at [minecraft.net](https://www.minecraft.net)). Game Pass for PC also includes Java Edition.

1. In Prism, click **Settings** (top bar), then **Accounts**.
2. Click **Add Microsoft**.
3. Prism shows a code and opens a Microsoft page in your browser. Sign in there and enter the code if asked.
4. Back in Prism, your account appears in the list. Click it and choose **Set Default** if it isn't already the default.

## Things to know

- **Never** type your Microsoft password into anything except Microsoft's own sign-in page.
- If you have more than one account, pick which one to play with from the account menu in the top right corner.
- "Offline" accounts only appear after you've signed in with a real account, and they can't join most servers.
