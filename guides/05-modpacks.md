# 5. Install a whole modpack

A modpack is a ready-made collection of mods and settings. Prism can install packs from several sites.

1. Click **Add Instance**.
2. On the left, pick where the pack comes from: **Modrinth**, **CurseForge**, **ATLauncher**, **Technic** or **FTB**.
3. Search for the pack, select it, and choose a version at the bottom (usually the newest).
4. Click **OK**. Prism downloads everything. CurseForge packs may ask you to download a few mods manually; see [Add mods](04-add-mods.md#some-mods-need-to-be-downloaded-manually-curseforge).
5. Select the new instance and click **Launch**.

## Got a pack as a file?

If you have a `.zip` or `.mrpack` file, use **Add Instance → Import**, choose the file, and click **OK**.

## Tips

- Big modpacks need more memory. See [Fix common problems → Not enough memory](06-troubleshooting.md#not-enough-memory).
- To update a pack, check the pack's page for instructions. Many packs can be updated from **Edit → Version** or by installing the new version as a new instance and copying your `saves` folder over.
- Want to play with friends? Everyone needs the **same pack and version**, and the server must run it too.
